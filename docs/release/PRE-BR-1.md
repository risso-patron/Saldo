# PRE-BR-1 — Registro histórico de la etapa previa a la primera Baseline Release

**Naturaleza de este documento:** registro histórico. No es una auditoría, no es un roadmap, no modifica ni reinterpreta ningún hallazgo de `RC-1.md` ni el contenido certificado de `BR-1.md`.

---

## 1. Propósito

PRE-BR-1 representa el período de desarrollo previo a la primera línea base oficial del proyecto (`BR-1`). Corresponde a las primeras iteraciones del producto: en esta etapa todavía no existía ninguna Baseline Release, y el objetivo principal no era validar el producto con usuarios de forma sistemática, sino **construir y estabilizar SALDO hasta llegar a un estado certificable como BR-1**.

Este documento no reconstruye esa etapa en detalle — solo la registra como contexto, para que quede explícito que el producto no nació directamente en BR-1, sino que llegó ahí después de un período previo de desarrollo e iteración.

## 2. Usuarios pioneros

Durante la etapa PRE-BR-1 participaron **aproximadamente 11 usuarios**, identificados colectivamente como **Cohorte 0**.

- Utilizaron versiones del producto anteriores a BR-1 — es decir, previas a la primera línea base oficialmente certificada.
- Su feedback fue utilizado para mejorar la aplicación durante esta etapa de construcción y estabilización, antes de congelar BR-1.
- No se identifica a ninguna persona por nombre ni se registra ningún dato personal en este documento.

## 3. Alcance

El feedback obtenido durante PRE-BR-1 se utilizó para:

- Detectar problemas funcionales del producto.
- Mejorar la experiencia de uso.
- Estabilizar la aplicación en el camino hacia BR-1.

Este feedback fue insumo del proceso de construcción previo a la línea base — **no constituye, ni forma parte de, la validación oficial de BR-2**. La Cohorte 0 y su feedback pertenecen a una etapa distinta, anterior a la existencia de una línea base certificada; no aporta métricas ni evidencia válida para el programa de validación diseñado en BR-2.

## 4. Relación con BR-1

- **BR-1** constituye el primer estado oficialmente certificado del producto — la primera fotografía estable, reproducible y trazable de SALDO.
- **PRE-BR-1** es únicamente el registro histórico de cómo se llegó hasta esa línea base: el período de desarrollo e iteración previo, sin el cual BR-1 no habría existido, pero que en sí mismo nunca fue certificado ni congelado como baseline.

## 5. Cierre

Toda la validación formal del producto comienza a partir de **BR-2**, utilizando nuevas cohortes de usuarios sobre la línea base ya certificada (`BR-1`). La Cohorte 0 y el período PRE-BR-1 quedan registrados como antecedente histórico, fuera del alcance de esa validación formal.
